# 🛡️ Cyber Deception Lab

A local cybersecurity deception and threat-detection lab designed to simulate attacker interaction with deceptive resources and analyze suspicious behaviour.

## 🎯 Project Objective

The Cyber Deception Lab uses decoy resources to attract and identify suspicious activity.

Instead of simply blocking an attacker, the system records their interactions with deceptive endpoints and converts those actions into a threat assessment.

## 🧠 How It Works

```text
Attacker Activity
       ↓
Decoy Web Application
       ↓
Activity Logging
       ↓
Threat Detection
       ↓
Behaviour Correlation
       ↓
Threat Score
       ↓
Security Dashboard
